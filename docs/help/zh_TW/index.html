編輯 Dock

此 Dock 的修改立即生效。「關閉」只關閉編輯器，不撤銷修改；圖釘用於保持視窗開啟。「新增… → 再製 Dock」會從原始 Dock 建立獨立副本；「移除」移除目前 Dock。

開啟「進階」後會顯示更多控制項；標示為「進階」的選項在基本編輯器中不可見。

行為

此 Dock 的可見性、延遲、操作、項目行為、浮動間距和環境選項。

視窗中的選項用途與範圍
可見性
螢幕 / 位置Screen / Location選擇此 Dock 的螢幕與邊緣。多螢幕時，「所有螢幕上」和「所有次要螢幕上」會建立連動複本；詳見「獨立副本與複本」。
對齊Alignment設定 Dock 在螢幕邊緣上的位置。「項目對齊」設定 Dock 內元件的位置。
永遠可見Always Visible保持顯示，並在視窗管理員支援時為 Dock 保留桌面空間。
自動隱藏Auto Hide隱藏 Dock，直到滑鼠進入觸發區域。
躲避作用中的視窗Dodge Active作用中視窗接觸 Dock 區域時隱藏，滑鼠進入時顯示。
躲避最大化的視窗Dodge Maximized僅當此螢幕上有最大化的作用中視窗時隱藏，滑鼠進入時顯示。
躲避所有視窗Dodge All Windows任何視窗接觸 Dock 區域時隱藏，滑鼠進入時顯示。
視窗在下面Windows Go Below讓 Dock 保持在視窗上方，視窗可以放到 Dock 下方。
視窗可覆蓋Windows Can Cover允許視窗覆蓋 Dock；滑鼠到達螢幕邊緣時，Dock 會來到前方。
視窗永可覆蓋Windows Always Cover讓視窗始終位於 Dock 上方，Dock 保持在視窗後方。
延遲
延遲 / 顯示 / 隱藏Delay / Show / Hide設定顯示和隱藏前的等待時間，單位為毫秒。增加延遲可減少誤觸。
操作
追蹤 進階Track選擇空白區域操作跟隨哪個作用中視窗：目前螢幕的作用中視窗，或所有螢幕的作用中視窗。
左鍵 / 拖曳作用中視窗 進階Left Button / Drag Active Window啟用後，可在 Dock 空白處按住左鍵拖曳，移動作用中視窗或最大化/還原作用中視窗。
中鍵 / 關閉作用中視窗 進階Middle Button / Close Active Window啟用後，可在 Dock 空白處按中鍵關閉追蹤的作用中視窗。
滑鼠滾輪 進階Mouse wheel選擇在 Dock 空白處捲動滾輪時的操作：無動作、切換桌面、切換活動、切換工作，或切換並最小化工作。
項目
游標懸停時顯示窄標題提示Thin title tooltips on hovering顯示精簡的元件標題提示。工作視窗預覽由工作頁的「懸停」動作單獨控制。
游標懸停時放大元件Zoom widgets on hovering允許元件隨 Dock 縮放。關閉後元件圖示保持銳利，但工作圖示和啟動器仍會縮放。
透過滑鼠滾輪展開彈出方塊Expand popup through mouse wheel在支援的元件上捲動滾輪，以顯示或隱藏其彈出視窗。
必要時自動調整大小Adjust size automatically when needed項目超出可用長度時縮小，能夠放下時再恢復大小。
以位置全域快捷鍵為基礎啟用Activate based on position global shortcuts允許全域位置快捷鍵啟動此 Dock 中的項目。每個佈局只應有一個 Dock 使用此功能。
浮動
使用者互動一律使用浮動間距 進階Always use floating gap for user interaction將浮動間隙計入元件和視窗的互動區域。
為最大化視窗隱藏浮動間距 進階Hide floating gap for maximized windows最大化視窗需要螢幕邊緣時，移除浮動間隙。
延遲隱藏浮動間距直到滑鼠離開 進階Delay floating gap hiding until mouse leaves等滑鼠離開後再隱藏浮動間隙，避免誤點附近的项目。
顯示時鏡像浮動間距 進階Mirror floating gap when it is shown在「永遠可見」模式下，在 Dock 另一側鏡像浮動間隙。
環境
桌面變更時提升 進階Raise on desktop change切換虛擬桌面時暫時顯示 Dock。「永遠可見」和「視窗在下面」模式不使用此選項。

外觀

外邊距、顏色、半徑/陰影、動態長度調整、動態可見性和例外情況需要開啟「進階」。

視窗中的選項用途與範圍
項目
Dock 樣式Dock Style選擇「經典」或「現代」。切換樣式會套用該樣式的預設，可能調整面板大小、縮放、圖示大小、浮動間隙和指示器樣式；切換後請檢查其他外觀選項。
絕對大小 / 相對大小Absolute size / Relative size以像素或螢幕比例設定圖示大小。高 DPI 或多螢幕環境適合使用相對大小。
懸停縮放Zoom on hover設定滑鼠懸停時項目的放大量。
長度
最大 / 最小 / 位移Maximum / Minimum / Offset設定 Dock 的最大、最小長度，並沿螢幕邊緣移動它。
動態長度調整 進階Dynamic Length Adjustments存在最大化視窗時把面板長度擴展到最大。需要先啟用背景。
外邊距
外邊距 / 長度 / 厚度 / 浮動間距 進階Margins / Length / Thickness / Floating gap分別設定沿 Dock 長度方向的外邊距、厚度方向的外邊距，以及 Dock 與螢幕邊緣之間的間隙。
顏色
顏色 / 調色盤 進階Colors / Palette選擇 Plasma 佈景主題顏色、深色、淺色、佈局自訂顏色、反轉，或基於桌面背景的智慧顏色。佈局自訂顏色使用佈局自己的配色方案；智慧顏色跟隨桌布。
背景
背景Background「背景」是開關。啟用後，可用下方的控制項設定厚度、不透明度、半徑和陰影。
不透明度 / 忙碌時不透明度Opacity / Busy Opacity設定背景不透明度。同時啟用「非必要時隱藏背景」和「接觸任何視窗時都偏好不透明的背景」時，同一滑桿會顯示為「忙碌時不透明度」。「預設」使用佈景主題預設值。
半徑 / 陰影 進階Radius / Shadow設定背景圓角半徑和陰影大小。「預設」使用佈景主題預設值。
模糊效果 / 陰影 / 輪廓 / 所有角落 進階Blur / Shadows / Outline / All Corners啟用背景模糊、背景陰影、輪廓和圓角。「所有角落」只在特定的浮動/兩端對齊幾何條件下可用。
動態可見性
接觸任何視窗時都偏好不透明的背景 進階Prefer opaque background when touching any window視窗接觸 Dock 時移除背景透明度。
非必要時隱藏背景 進階Hide background when not needed除非視窗接觸 Dock 或桌面背景忙碌，否則隱藏背景。
為最大化視窗隱藏背景陰影 進階Hide background shadow for maximized windows最大化的作用中視窗接觸 Dock 時隱藏背景陰影。
例外情況
展開的元件偏好 Plasma 背景與顏色 進階Prefer Plasma background and colors for expanded applets元件彈出視窗展開時，使用不透明的 Plasma 樣式背景和 Plasma 配色。

效果

視窗中的選項用途與範圍
陰影
陰影Shadows開啟或關閉元件陰影。關閉後，大小和不透明度不可用。
大小 / 不透明度Size / Opacity設定元件陰影的大小和不透明度。
預設色彩 / 佈景主題色彩 / 自訂色彩Default Color / Theme Color / custom color選擇預設陰影顏色、佈景主題調色盤顏色，或點擊顏色色塊選擇自訂顏色。
動畫
動畫 / x1 / x2 / x3Animations / x1 / x2 / x3開啟或關閉所有 Dock 動畫。x1 為正常速度，x2 較慢，x3 最慢。
指示器
指示器Indicators開啟或關閉作用中工作指示器。啟用後可選擇 Latte 指示器或自訂指示器外掛程式；外掛程式專屬選項會顯示在其分頁中。

工作

徽章、動畫、捲動、操作以及部分互動/過濾選項需要開啟「進階」。開啟「僅顯示啟動器並隱藏所有工作」會停用與視窗相關的操作和過濾。

視窗中的選項用途與範圍
徽章
工作通知 進階Notifications from tasks在工作圖示上顯示未讀通知數量。
工作進度資訊 進階Progress information for tasks顯示進度徽章，例如 Dolphin 複製檔案時。
工作的音訊播放 進階Audio playing from tasks為正在播放聲音的應用程式顯示音訊徽章。
通知徽章使用醒目顏色 進階Prominent color for notification badge使用更醒目（通常是紅色）的通知徽章。需要先開啟「工作通知」。
捲動音訊徽章時變更音量 進階Change volume when scrolling audio badge點擊音訊徽章可靜音/取消靜音，捲動滾輪可調整音量。需要先開啟「工作的音訊播放」。
互動
啟動器僅於目前的工作元件新增Launchers are added only in current tasks applet拖入的啟動器只新增到目前工作元件，不會成為獨立元件或進入其他工作元件。
右鍵選單中的視窗動作 進階Window actions in the context menu在工作右鍵選單中顯示視窗專屬操作。
預覽視窗以彈出式視窗顯示 進階Preview window behaves as popup讓預覽以彈出式視窗而不是工具提示的方式顯示。需要先把「懸停」動作設為預覽；此選項只改變顯示方式。
以位置為基礎的快捷鍵僅套用於目前工作 進階Based on position shortcuts apply only on current tasks把以位置為基礎的全域快捷鍵限制在此工作元件內。
過濾
只顯示目前螢幕上的工作Show only tasks from the current screen只顯示此 Dock 所在螢幕上的視窗。
只顯示目前桌面上的工作Show only tasks from the current desktop只顯示目前虛擬桌面的視窗。
只顯示啟動器中的工作 進階Show only tasks from launchers只顯示啟動器清單中已有應用程式的視窗。
僅顯示啟動器並隱藏所有工作 進階Show only launchers and hide all tasks只顯示啟動器圖示，隱藏正在執行的工作。這也會停用與視窗相關的操作和過濾。
同一個應用程式僅顯示分組好的工作 進階Show only grouped tasks for same application預設把同一應用程式的視窗分為一組。
動畫
工作被觸發時彈跳啟動器 進階Bounce launchers when triggered啟動器被觸發時顯示動畫。
需要注意的工作彈跳 進階Bounce tasks that need attention需要注意的工作顯示動畫。
單一視窗滑入和滑出 進階Slide in and out single windows新視窗開啟或關閉時顯示滑入/滑出動畫。
工作群組中的新視窗彈跳 進階Grouped tasks bounce their new windows工作群組中新增視窗時顯示彈跳動畫。
工作群組中的關閉視窗滑出 進階Grouped tasks slide out their closed windows工作群組中視窗關閉時顯示滑出動畫。
啟動器
唯一群組Unique Group此工作元件使用獨立的啟動器清單。
佈局群組Layout Group與同一佈局中使用該群組的工作元件共用啟動器。只有 Dock 已經使用「佈局群組」時才會顯示此按鈕。
全域群組Global Group與所有佈局中使用該群組的工作元件共用啟動器。
捲動
捲動 進階Scrolling工作超出可用空間時啟用捲動。
手動 進階Manual選擇「停用捲動」「僅垂直/水平捲動」或「水平和垂直捲動」。單方向選項取決於 Dock 方向。
自動 進階Automatic開啟或關閉自動捲動。
操作
點擊滑鼠左鍵 進階Left Click左鍵點擊工作時的動作：無、關閉視窗或群組、新執行個體、最小化/還原、切換工作、切換工作分組、展示視窗、預覽視窗、醒目提示視窗，或預覽並醒目提示視窗。
點擊滑鼠中鍵 進階Middle Click中鍵點擊工作時的動作，選擇範圍與左鍵點擊相同。
懸停 進階Hover懸停動作：無、預覽視窗、醒目提示視窗，或預覽並醒目提示視窗。工作標題提示由「行為」頁控制。
滾輪 進階Wheel滾輪動作：無、切換工作，或切換並最小化工作。
修飾鍵 + 點擊 進階Modifier + click按住 Shift、Ctrl、Alt 或 Meta 再左/中/右鍵點擊，執行額外動作。選擇修飾鍵、滑鼠鍵和動作；它與上方的主要操作分別設定。

Plasma 6 中 KActivities 支援不可靠，因此「只顯示目前活動裡的工作」過濾器目前被隱藏。

設定 Latte

「佈局編輯器」管理佈局及其 Dock；「偏好設定」控制應用程式全域行為。「套用」儲存目前分頁的待處理修改，「重設」恢復該頁的已儲存狀態，「恢復預設」準備預設值供你確認。「螢幕…」管理已儲存的螢幕參照。

佈局編輯器

視窗中的選項用途與範圍
一次一種佈局Single layout at all times所有活動使用同一佈局。
以活動為基礎的多重佈局Multiple layouts based on activities依活動指派不同佈局；多個佈局可以同時載入。
切換Switch啟用所選佈局。請先套用待處理修改；有未儲存修改時 Latte 不會切換。
活動...Activities...開啟 Plasma 的活動管理器。使用「活動」欄或「已啟用」把此佈局指派給活動。
新增 / 再製 / 移除New / Duplicate / Remove建立、複製或移除佈局。這裡的「再製」複製整個佈局，不是單一 Dock。使用中和鎖定的佈局不能移除。
已啟用Enabled把此佈局指派給一個或多個活動，使 Plasma 活動可以啟用它。僅在多佈局模式下顯示。
唯讀Read Only保護佈局設定不被修改。
詳細資訊...Details...開啟佈局詳細資訊對話方塊，編輯圖示、自訂顏色、彈出邊距和右鍵選單可見性。
Dock...Docks...開啟此佈局的 Dock 清單：名稱、螢幕、邊緣、對齊、包含的元件，以及新增/再製/移除/匯入/匯出。
匯入... / 匯出...Import... / Export...從本機檔案或 KDE 商店匯入佈局；匯出佈局用於備份或作為範本。「檔案 → 匯入設定／匯出設定」處理完整應用程式設定備份。
名稱 / 在選單中 / 活動Name / In Menu / Activities佈局清單有三欄：名稱、在選單中、活動。可直接在清單中編輯名稱和活動；「在選單中」控制佈局是否出現在 Dock 的「佈局」選單中。

佈局詳細資訊

透過「佈局編輯器 → 詳細資訊...」開啟，編輯所選佈局。

視窗中的選項用途與範圍
佈局Layout選擇要編輯的佈局。
圖示Icon為佈局選擇圖示。清除按鈕會移除圖示。
自訂顏色Custom Colors為此佈局選擇自訂配色方案檔案。

盡可能在佈局右鍵選單中顯示Show in layouts context menu when possible目前活動允許時，在 Dock 的「佈局」選單中顯示此佈局。

Dock 對話方塊

透過「佈局編輯器 → Dock...」開啟，管理所選佈局中的 Dock。

視窗中的選項用途與範圍
欄位
名稱NameDock 名稱。按兩下可重新命名。
螢幕ScreenDock 所屬螢幕，包括「主螢幕上」「所有螢幕上」和「所有次要螢幕上」。
邊緣EdgeDock 使用的螢幕邊緣。
對齊AlignmentDock 沿邊緣的對齊方式。
包含IncludesDock 包含的元件和子容器。此欄位為唯讀。
按鈕
新增New從範本建立 Dock。
再製Duplicate為所選 Dock 建立獨立副本；如果所選的是複本，則再建立一個複本。
移除Remove移除所選 Dock。複本會隨原始 Dock 一起移除。
匯入...Import...從本機範本檔案匯入 Dock。
匯出...Export...把所選 Dock 匯出為備份或範本。範本對話方塊可選擇要包含哪些元件設定；不要包含電子郵件、行事曆等含個人資料的元件。

螢幕對話方塊

透過「檔案 → 螢幕...」開啟，清理 Latte 儲存的螢幕參照。

視窗中的選項用途與範圍
螢幕清單Screen list列出 Latte 中儲存的螢幕參照，包括已中斷連線的螢幕。
選擇廢棄螢幕Select obsolete screens只勾選已不存在的螢幕。使用中的螢幕以及被佈局參照的螢幕不能移除。
全部取消選取Deselect All清除選取，以便重新選擇。

獨立副本與複本

「再製」和「複本」在螢幕上看起來相似，但行為不同。再製會建立全新的獨立 Dock；複本是同一個 Dock 在另一個螢幕上的連動檢視。是否需要分開設定這個 Dock，決定你該選哪一種。

建立獨立副本

請在原始 Dock 上使用下列任一方式，不要在複本上操作：

  • 在 Dock 上按滑鼠右鍵，選擇再製 Dock。
  • 開啟編輯 Dock，選擇新增… → 再製 Dock。
  • 開啟設定 Latte → 佈局編輯器 → Dock…，選取 Dock 後選擇再製。

副本會取得新的 Dock 與元件 ID，並複製目前設定一次。之後可以獨立變更它的螢幕、邊緣、大小、外觀、行為、元件和啟動器。它在佈局中是獨立項目，可用移除 Dock 刪除。

在「Dock」對話方塊中再製複本，得到的仍然是同一個原始 Dock 的複本，而不是獨立副本。若要從複本建立獨立 Dock，請先選擇編輯原始 Dock…，再從原始 Dock 執行再製。

如果原始 Dock 使用全域群組，副本也會使用該群組並共用啟動器。若希望副本擁有獨立的啟動器清單，請在副本上選擇唯一群組。佈局群組只有在 Dock 已經使用它時才可用。

建立複本

複本由原始 Dock 的螢幕模式建立，而不是透過再製 Dock：

  • 編輯 Dock → 螢幕 → 所有螢幕上：原始 Dock 保留在主螢幕，Latte 會在每個次要螢幕上建立一個複本。
  • 編輯 Dock → 螢幕 → 所有次要螢幕上：原始 Dock 保留在其中一個次要螢幕，Latte 會在其餘次要螢幕上建立複本。

螢幕配置變更時，Latte 會自動建立和移除複本。要移除複本，請把原始 Dock 改回主螢幕上，或改為某個特定螢幕。複本的右鍵選單中沒有移除 Dock；請使用其中的編輯原始 Dock… 進行設定。

從複本開啟編輯器時，實際開啟的是原始 Dock 的設定，因為複本共用 Dock 設定。在複本上修改元件設定也會更新原始 Dock。
