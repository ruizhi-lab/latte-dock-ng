Editar Barra

As alterações têm efeito imediato. Fechar oculta o editor; não desfaz as alterações. Fixar mantém o editor aberto. Adicionar… → Duplicar Barra cria uma cópia independente de uma barra original; Remover elimina a barra atual. A mudança de separadores mantém a janela no lugar. O modo avançado dimensiona a janela para a sua página mais longa, dentro do espaço de ecrã disponível. Páginas mais longas deslocam-se dentro da janela. Arraste o canto de redimensionamento para ajustar o tamanho da janela em qualquer modo de edição.

O modo avançado revela mais controlos. As opções marcadas como Avançadas estão ocultas no editor básico.

Tarefas

Os lançadores de tarefas começam a reordenar-se em outras docas que partilham a lista de lançadores depois de soltar o ícone. A ordem pode demorar um momento a estabilizar. Os espaços dos separadores mantêm-se no lugar quando a doca de destino guarda a nova ordem. Arrastar uma aplicação já fixada mantém o seu lançador existente, incluindo quando esse lançador segue a aplicação predefinida do sistema. Os novos separadores ocupam espaço assim que atingem o intervalo selecionado.

Ao adicionar ou arrastar um widget ao lado de um separador na extremidade da área de tarefas ou da bandeja do sistema, o widget é colocado no exterior do separador. O separador permanece junto à área de tarefas ou à bandeja.

Ao fixar uma aplicação a partir do menu de aplicações, o seu ícone aparece antes de quaisquer separadores no final da lista de tarefas. O separador à direita pertence ao grupo de fixados, pelo que as aplicações em execução que não estão fixadas aparecem além dele.

O espaço da tarefa permanece destacado e o ícone continua visível enquanto o arrasta para reordenar as tarefas. Quando uma nova tarefa desliza para dentro, a doca começa a reservar o seu espaço a partir do tamanho inicial da animação.

As opções de Insígnias, Animações, Deslocação, Ações e algumas opções de Interação/Filtros requerem o modo Avançado. Mostrar apenas lançadores e ocultar todas as tarefas desativa as ações e filtros relacionados com janelas.

Cópias Independentes e Clones

Uma duplicata e um clone parecem semelhantes no ecrã, mas comportam-se de forma diferente. Uma duplicata é uma nova barra de ferramentas independente. Um clone é a mesma barra de ferramentas mostrada em outro ecrã. Escolha com base em se deseja configurar esta barra de ferramentas separadamente.

Criar uma cópia independente

Use qualquer um destes métodos na barra de ferramentas original, não em um clone:

  • Clique com o botão direito na barra de ferramentas e escolha Duplicar Barra de Ferramentas.
  • Abra Editar Barra de Ferramentas e escolha Adicionar… → Duplicar Barra de Ferramentas.
  • Abra Configurar Latte → Editor de Layouts → Barras de Ferramentas…, selecione a barra de ferramentas e escolha Duplicar.

A cópia recebe novos IDs de barra de ferramentas e de widget e copia as configurações atuais uma vez. Depois disso, pode alterar o ecrã, a borda, o tamanho, a aparência, o comportamento, os widgets e os lançadores independentemente. É uma entrada separada no layout e pode ser removida com Remover Barra de Ferramentas.

Duplicar um clone a partir do diálogo Barras de Ferramentas cria outro clone do mesmo original, não uma barra de ferramentas independente. Para criar uma barra de ferramentas independente a partir de um clone, primeiro abra Editar Barra de Ferramentas Original… e duplique o original.

Se o original usar Grupo Global, a cópia também o usará e compartilhará os lançadores. Escolha Grupo Único na cópia se desejar uma lista de lançadores separada. Grupo de Layout está disponível apenas quando o dock já o utiliza.

Criar clones

Os clones são criados pelo modo de ecrã de um dock original, não por Duplicar Dock:

  • Editar Dock → Ecrã → Em Todos os Ecrãs: o original permanece no ecrã principal e o Latte cria um clone em cada ecrã secundário.
  • Editar Dock → Ecrã → Em Todos os Ecrãs Secundários: o original permanece num ecrã secundário e o Latte cria clones nos restantes ecrãs secundários.

O Latte cria e remove clones automaticamente quando o layout do ecrã muda. Para remover clones, defina o original novamente para No Ecrã Principal ou para um ecrã específico. Um clone não tem entrada Remover Dock no seu menu de contexto; utilize Editar Dock Original… para o configurar.

Abrir o editor a partir de um clone abre sempre as definições do dock original, porque os clones partilham a configuração do dock. As definições de widgets alteradas num clone também atualizam o original.
