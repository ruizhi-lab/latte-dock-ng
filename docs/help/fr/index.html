LATTE DOCK NG

Guide de l'utilisateur de Latte Dock NG

Ces instructions décrivent les options actuelles. Le mode avancé, le style de dock et les plugins installés peuvent modifier les contrôles visibles. Les options marquées Avancé sont masquées dans l'éditeur de base.

Seuls les guides traduits sont répertoriés. Les autres langues d'interface ouvrent le guide en anglais.

Modifier le dock

Les modifications prennent effet immédiatement. Fermer masque l'éditeur ; cela n'annule pas les modifications. Épingler maintient l'éditeur ouvert. Ajouter… → Dupliquer le dock crée une copie indépendante d'un dock original ; Supprimer retire le dock actuel. Le changement d'onglet conserve la position de la fenêtre. Le mode avancé dimensionne la fenêtre pour sa page la plus longue, dans l'espace d'écran disponible. Les pages plus longues défilent à l'intérieur de la fenêtre. Faites glisser le coin de redimensionnement pour ajuster la taille de la fenêtre dans les deux modes d'édition.

Le mode avancé révèle plus de contrôles. Les options marquées Avancé sont masquées dans l'éditeur de base.

Tâches

Les lanceurs de tâches commencent à se réorganiser sur les autres docks qui partagent la liste des lanceurs après le dépôt de l'icône. L'ordre peut mettre un moment à se stabiliser. Les espaces séparateurs restent en place lorsque le dock récepteur enregistre le nouvel ordre. Le déplacement d'une application déjà épinglée conserve son lanceur existant, y compris lorsque ce lanceur suit l'application par défaut du système. Les nouveaux séparateurs prennent de l'espace une fois qu'ils atteignent l'espace sélectionné.

Lorsque vous ajoutez ou déplacez un widget à côté d'un séparateur situé au bord de la zone des tâches ou de la zone de notification système, le widget se place à l'extérieur du séparateur. Le séparateur reste adjacent à la zone des tâches ou à la zone de notification système.

Lorsque vous épinglez une application depuis le menu des applications, son icône apparaît avant tous les séparateurs situés à la fin de la liste des tâches. Le séparateur de droite appartient au groupe épinglé, de sorte que les applications en cours d'exécution qui ne sont pas épinglées apparaissent au-delà de celui-ci.

L'emplacement de la tâche reste en surbrillance et l'icône reste visible pendant que vous la déplacez pour réorganiser les tâches. Lorsqu'une nouvelle tâche s'insère, le dock commence à réserver son emplacement dès la taille initiale de l'animation.

Les options Badges, Animations, Défilement, Actions et certaines options Interaction/Filtres nécessitent le mode Avancé. L'affichage des lanceurs uniquement et la masquage de toutes les tâches désactivent les actions et les filtres liés aux fenêtres.

Configurer Latte

L'éditeur de dispositions gère les dispositions et leurs docks. Les préférences contrôlent le comportement de l'application. Appliquer enregistre les modifications en attente dans l'onglet actuel ; Réinitialiser restaure l'état enregistré de cet onglet ; Restaurer les valeurs par défaut prépare les valeurs par défaut pour examen. Copies indépendantes et clones

Un duplicata et un clone se ressemblent à l'écran mais se comportent différemment. Un duplicata est un nouveau dock indépendant. Un clone est le même dock affiché sur un autre écran. Choisissez en fonction de votre souhait de configurer ce dock séparément.

Créer une copie indépendante

Utilisez l'une de ces méthodes sur le dock original, et non sur un clone :

  • Cliquez avec le bouton droit sur le dock et choisissez Dupliquer le dock.
  • Ouvrez Modifier le dock et choisissez Ajouter… → Dupliquer le dock.
  • Ouvrez Configurer Latte → Éditeur de mise en page → Docks…, sélectionnez le dock, et choisissez Dupliquer.

La copie reçoit de nouveaux identifiants de dock et de widget et copie les paramètres actuels une seule fois. Ensuite, vous pouvez modifier indépendamment son écran, son bord, sa taille, son apparence, son comportement, ses widgets et ses lanceurs. C'est une entrée distincte dans la mise en page et elle peut être supprimée avec Supprimer le dock.

La duplication d'un clone depuis la boîte de dialogue Docks crée un autre clone du même original, et non un dock indépendant. Pour créer un dock indépendant à partir d'un clone, ouvrez d'abord Modifier le dock original… et dupliquez l'original.

Si l'original utilise Groupe global, la copie l'utilise également et partage les lanceurs. Choisissez Groupe unique sur la copie si vous souhaitez une liste de lanceurs séparée. Groupe de mise en page n'est disponible que si le dock l'utilise déjà.

Créer des clones

Les clones sont créés par le mode d'écran d'un dock original, et non par Dupliquer le dock:

  • Modifier le dock → Écran → Sur tous les écrans : l'original reste sur l'écran principal, et Latte crée un clone sur chaque écran secondaire.
  • Modifier le dock → Écran → Sur tous les écrans secondaires : l'original reste sur un écran secondaire, et Latte crée des clones sur les écrans secondaires restants.

Latte crée et supprime automatiquement les clones lorsque la disposition des écrans change. Pour supprimer les clones, remettez l'original sur Sur l'écran principal ou sur un écran spécifique. Un clone n'a pas d'entrée Supprimer le dock dans son menu contextuel ; utilisez Modifier le dock original… pour le configurer.

L'ouverture de l'éditeur depuis un clone ouvre toujours les paramètres du dock original, car les clones partagent la configuration du dock. Les paramètres des widgets modifiés sur un clone mettent également à jour l'original.
