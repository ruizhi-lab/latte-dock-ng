LATTE DOCK NG

Wužiwarski přewodnik Latte Dock NG

Tute instrukcije wopisuja aktualne opcije. Rozšěrjeny modus, stil dokow a instalowane pluginy móža změnić, kotre kontrolne elementy su widźomne. Opcije, kotrež su jako Rozšěrjene woznamjenjene, su w zakładnym editorje schowane.

Jenož přełožene přewodniki su wupisane. Druhe rěčne warianty interfejsa wočinja jendźelski přewodnik.

Dok wobdźěłać

Změny so hnydom wuskutkuja. Zamknjenje schowa editor; njewotwołuje změny. Připinjowanje dźerži editor wočiny. Přidać… → Dok duplikować wutworja niezawisnu kopiju originalneho doka; Wotstronić wotstroni aktualny dok. Přepinjenje tabow dźerži wokno na městnje. Rozšěrjeny modus wulkosć wokna za jeho najdlěšu stronu přiměri, w ramikach dostupneho wobrazowkoweho ruma. Dłěše strony so wnutř wokna posuwaja. Wulkosć wokna so w kóždym wobdźěłanskim modusu přez ćahjenje rožka za změnu wulkosće přiměri.

Rozšěrjony mod zwobraznja wjace kontrolow. Opcije, kotrež su jako Rozšěrjene woznamjenjene, su w zakładnym editorje schowane.

Zachowanje so

Widźomnosć, spóždanje, akcije, zachowanje so zapiskow, pływacy mjezot a opcije za wobswět za tutón dok.

Opcija w woknjeŠto wón kontroluje
Widźomnosć
Ekran / MěstnoWubjerće ekran a kónc za tutón dok. Při wjacorych ekranach wutworja Na wšěch ekranach a Na wšěch sekundarnych ekranach zwjazane kopije. Wobhladajće sej Samostatne kopije a Kopije.
WusměrjenjePozicionujće dok podłu kónca ekrana. Wusměrjenje zapiskow kontroluje, hdźež so widgety w dokje namakaja.
Stajnje widźomnyZachowajće dok widźomny a rezervujće desktopowy rum, hdyž to wokjowy manager podpěruje.
Awtomatisce schowaćSchowajće dok, doniž pointer njedóńdźe do jeho aktiwaciskeho ruma.
Wobchadźeć aktiwneSchowajće, hdyž so aktiwne wokno doka dótka, a zwobrazńće dok, hdyž so pointer do njeho zadobywa.
Wobchadźeć maksimalizowaneSchowajće jenož, hdyž je maksimalizowane wokno na tutym ekranje aktiwne, a zwobrazńće dok, hdyž so pointer do njeho zadobywa.
Wobchadźeć wšě woknaSchowajće, hdyž so kóžde wokno doka dótka, a zwobrazńće dok, hdyž so pointer do njeho zadobywa.
Wokna so pod nimZachowajće dok nad woknami; wokna móža so pod nim pozicionować.
Wokna móža jeho přikryćDopušćće, zo wokna dok přikryja. Dok so na předni plan dóńdźe, hdyž so pointer k jeho ekranowemu kóncu dóńdźe.

Spóždanje
Spóždanje / Zwobraznić / SchowaćNastajće, kak dołho ma so čakać, prjedy hač so pokazanje abo schowanje započeje, w milisekundach. Dolepše čakanje pomjeńša njewotwisne spušćenje.

Nadawki

Po pušćenju ikony se započnu launcherji zadaćow na druhich dokach, kotrež so launcher-listu dźěleja, přerjadować. Porjad móže chwilku trjechić, doniž so njewustali. Města mjezowarjow so zachowaja, hdyž přijimacy dok nowy porjad składowaće. Ćehnjenje hižo připinjateje aplikacije zachowa jeje eksistowacy launcher, tež hdyž so tón launcher po systemowym standardnym programom orientuje. Nowe mjezowary wobsadźa městno, hdyž docpěja wubrane město.

Hdyž widget přidawaće abo ćehnjeće k mjezowarju na kóncu wobłuka zadaćow abo systemoweje blidowki, so widget wonka mjezowara zasadźi. Mjezowar so pola wobłuka zadaćow abo blidowki zachowa.

Hdyž aplikaciju z aplikaciskeho menuja připinjeće, so jeje ikona před wšěmi mjezowarami na kóncu lisćiny zadaćow jewi. Prawy mjezowar słuša k připinjatej skupinje, tak zo so běžace, njepřipinjate aplikacije za nim jewja.

Městno zadaće so wuzběhnje a ikona so widźomna wostanje, mjeztym zo ju za přerjadowanje zadaćow ćehnjeće. Hdyž so nowe zadaće zasunje, dok so započnje swoje městno wot initialneje animaciskeje wulkosće rezervować.

Woznamjenja, animacije, kotrowanje, akcije a někotre opcije interakcije/filtrow wumóžuja rozšěrjeny modus. Jenož launcherje zwobraznić a wšě zadaća schować zakazuje akcije a filtry zwjazane z woknom.

Niezawisne kopije a klony

Duplikat a klon wupadatej na wobrazowce podobnje, ale so wosobowje wěstej. Duplikat je nowy, niezawisny dok. Klon je samsny dok, kotryž so na druhej wobrazowce pokazuje. Wubjerće na zakładźe toho, hač chceće tutón dok separatnje konfigurować.

Niezawisnu kopiju wutworjeć

Wužiwajće kóždu z tutych metodow na originalnym dokje, nic na klonje:

  • Klikńće prawu myšowu na dok a wubjerće Duplicate Dock.
  • Wotewrěće Edit Dock a wubjerće Add… → Duplicate Dock.
  • Wotewrěće Configure Latte → Layouts Editor → Docks…, wubjerće dok a wubjerće Duplicate.

Kopija dóstawa nowe dokowe a widgetowe ID-y a kopěruje aktualne nastajenja jónu. Po tym móžeće jeje wobrazowku, kónc, wulkosć, wupad, zadźerženje, widgety a startery separatnje změnić. Je separaten zapis w layoutu a móže so z Remove Dock wotstronić.

Duplikowanje klona z dialoga Docks wutworjeje dalši klon samsneho originala, nic niezawisny dok. Zo byšće niezawisny dok z klona natwarił, wotewrěće najprjedy Edit Original Dock… a duplikujće original.

Jeli original Global Group wužiwa, kopija tež tutu wužiwa a dźěli startery. Wubjerće Unique Group na kopiji, jeli chceće separatnu lisćinu starterow. Layout Groupje k dispoziciji jenož, hdyž dok hižo wužiwa.

Klonować

Klony so tworja přez wobrazowy modus originalneho doka, nic přez Duplikować dok:

  • Editować dok → Wobraz → Na wšěch wobrazach: original wostanje na primarnym wobrazu, a Latte tworji klon na kóždym sekundarnym wobrazu.
  • Editować dok → Wobraz → Na wšěch sekundarnych wobrazach: original wostanje na jednym sekundarnym wobrazu, a Latte tworji klony na zwostanych sekundarnych wobrazach.

Latte tworji a wotstronja klony awtomatisce, hdyž so wobrazowe rozłoženje změni. Zo by klony wotstronił, staj original wróćo na Na primarnym wobrazu abo na jedyn specifiski wobraz. Klon njema Wotstronić dok zapisk w swojim kontekstowym menu; wužiwajće Editować originalny dok… tam, zo by jeho konfigurował.

Wotewrjenje editora z klona wotewrje stajnje nastajenja originalneho doka, dokelž klony dźěleja dokowu konfiguraciju. Nastajenja widgetow, kotrež so na klonu změnja, tež original aktualizuja.
