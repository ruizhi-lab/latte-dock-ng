本文按当前选项说明。高级模式、停靠栏样式及已安装插件会影响哪些选项可见；标注为“高级”的选项在基础编辑器中不可见。

编辑 Dock

此停靠栏的修改即时生效。“关闭”只关闭编辑器，不撤销修改；图钉用于保持窗口打开。“添加… → 复制停靠栏”会从原始停靠栏创建独立副本；“移除”移除当前停靠栏。

开启“高级”后会显示更多控件；标注为“高级”的选项在基础编辑器中不可见。

行为

此停靠栏的可见性、延迟、操作、项目行为、浮动间距和环境选项。

窗口中的选项用途与范围
可见性
屏幕 / 位置Screen / Location选择此停靠栏的屏幕与边缘。多屏时，“所有屏幕”和“所有次要屏幕”会创建联动克隆；详见“独立副本与克隆”。
对齐Alignment设置停靠栏在屏幕边缘上的位置。“项目对齐”设置栏内小部件的位置。
总是可见Always Visible保持显示，并在窗口管理器支持时为停靠栏保留桌面空间。
自动隐藏Auto Hide隐藏停靠栏，直到鼠标进入触发区域。
避开活动窗口Dodge Active活动窗口接触停靠栏区域时隐藏，鼠标进入时显示。
避开最大化窗口Dodge Maximized仅当此屏幕上有最大化的活动窗口时隐藏，鼠标进入时显示。
避开所有窗口Dodge All Windows任何窗口接触停靠栏区域时隐藏，鼠标进入时显示。
窗口位于后方Windows Go Below让停靠栏保持在窗口上方，窗口可以放到停靠栏下方。
窗口可覆盖Windows Can Cover允许窗口覆盖停靠栏；鼠标到达屏幕边缘时，停靠栏会来到前方。
窗口总是覆盖Windows Always Cover让窗口始终位于停靠栏上方，停靠栏保持在窗口后方。
延迟
延迟 / 显示 / 隐藏Delay / Show / Hide设置显示和隐藏前的等待时间，单位为毫秒。增大延迟可减少误触。
操作
跟踪 高级Track选择空白区域操作跟随哪个活动窗口：当前屏幕的活动窗口，或所有屏幕的活动窗口。
左键 / 拖动活动窗口 高级Left Button / Drag Active Window启用后，可在停靠栏空白处按住左键拖动，移动活动窗口或最大化/还原活动窗口。
中键 / 关闭活动窗口 高级Middle Button / Close Active Window启用后，可在停靠栏空白处单击中键关闭跟踪的活动窗口。
鼠标滚轮 高级Mouse wheel选择在停靠栏空白处滚动滚轮时的操作：无操作、切换桌面、切换活动、切换任务，或切换并最小化任务。
项目
悬停时显示窄标题提示Thin title tooltips on hovering显示精简的小部件标题提示。任务窗口预览由任务页的“悬停”动作单独控制。
悬停时放大小部件Zoom widgets on hovering允许小部件随停靠栏缩放。关闭后小部件图标保持锐利，但任务图标和启动器仍会缩放。
通过鼠标滚轮展开弹窗Expand popup through mouse wheel在受支持的小部件上滚动滚轮，以显示或隐藏其弹出窗口。
需要时自动调整大小Adjust size automatically when needed项目超出可用长度时缩小，能够放下时再恢复大小。
基于位置全局快捷键激活Activate based on position global shortcuts允许全局位置快捷键激活此停靠栏中的项目。每个布局只应有一个停靠栏使用此功能。
浮动
用户交互总是使用浮动间距 高级Always use floating gap for user interaction将浮动间隙计入小部件和窗口的交互区域。
隐藏最大化窗口的浮动间距 高级Hide floating gap for maximized windows最大化窗口需要屏幕边缘时，移除浮动间隙。
暂缓隐藏浮动间距直至鼠标离开 高级Delay floating gap hiding until mouse leaves等鼠标离开后再隐藏浮动间隙，避免误点附近的项目。
显示时镜像浮动间距 高级Mirror floating gap when it is shown在“总是可见”模式下，在停靠栏另一侧镜像浮动间隙。
环境
切换桌面时弹出 高级Raise on desktop change切换虚拟桌面时暂时显示停靠栏。“总是可见”和“窗口位于后方”模式不使用此选项。

外观

外边距、颜色、半径/阴影、动态长度调整、动态可见性和例外情况需要开启“高级”。

窗口中的选项用途与范围
项目
停靠栏样式Dock Style选择“经典”或“现代”。切换样式会套用该样式的预设，可能调整面板大小、缩放、图标大小、浮动间距和指示器样式；切换后请检查其他外观选项。
绝对大小 / 相对大小Absolute size / Relative size以像素或屏幕比例设置图标大小。高 DPI 或多屏环境适合使用相对大小。
悬停缩放Zoom on hover设置鼠标悬停时项目的放大量。
长度
最大 / 最小 / 偏移Maximum / Minimum / Offset设置停靠栏的最大、最小长度，并沿屏幕边缘移动它。
动态长度调整 高级Dynamic Length Adjustments存在最大化窗口时把面板长度扩展到最大。需要先启用背景。
外边距
外边距 / 长度 / 厚度 / 浮动间距 高级Margins / Length / Thickness / Floating gap分别设置沿停靠栏长度方向的外边距、厚度方向的外边距，以及停靠栏与屏幕边缘之间的间隙。
颜色
颜色 / 调色板 高级Colors / Palette选择 Plasma 主题颜色、深色、浅色、布局自定义颜色、反转，或基于桌面背景的智能颜色。布局自定义颜色使用布局自己的配色方案；智能颜色跟随壁纸。
背景
背景Background“背景”是开关。启用后，可用下面的控件设置厚度、不透明度、半径和阴影。
不透明度 / 繁忙时不透明度Opacity / Busy Opacity设置背景不透明度。同时启用“不需要时隐藏背景”和“贴靠窗口时背景不透明”时，同一滑块会显示为“繁忙时不透明度”。“默认”使用主题默认值。
半径 / 阴影 高级Radius / Shadow设置背景圆角半径和阴影大小。“默认”使用主题默认值。
模糊 / 阴影 / 描边 / 所有边角 高级Blur / Shadows / Outline / All Corners启用背景模糊、背景阴影、描边和圆角。“所有边角”只在特定的浮动/两端对齐几何条件下可用。
动态可见性
贴靠窗口时背景不透明 高级Prefer opaque background when touching any window窗口接触停靠栏时移除背景透明度。
不需要时隐藏背景 高级Hide background when not needed除非窗口接触停靠栏或桌面背景繁忙，否则隐藏背景。
最大化窗口时隐藏背景阴影 高级Hide background shadow for maximized windows最大化的活动窗口接触停靠栏时隐藏背景阴影。
例外情况
小部件展开时首选 Plasma 背景与颜色 高级Prefer Plasma background and colors for expanded applets小部件弹出窗口展开时，使用不透明的 Plasma 样式背景和 Plasma 配色。

任务

徽章、动画、滚动、操作以及部分交互/过滤选项需要开启“高级”。开启“只显示启动器并隐藏所有任务”会禁用与窗口相关的操作和过滤。

窗口中的选项用途与范围

交互
仅在当前任务小部件中添加启动器Launchers are added only in current tasks applet拖入的启动器只添加到当前任务小部件，不会成为独立小部件或进入其他任务小部件。

过滤

动画
任务被触发时跳动启动器 高级Bounce launchers when triggered启动器被触发时显示动画。

单个窗口滑入和滑出 高级Slide in and out single windows新窗口打开或关闭时显示滑入/滑出动画。
任务组中的新窗口跳动 高级Grouped tasks bounce their new windows任务组中新增窗口时显示跳动动画。

启动器
唯一组Unique Group此任务小部件使用独立的启动器列表。
布局组Layout Group与同一布局中使用该组的任务小部件共享启动器。只有停靠栏已经使用“布局组”时才会显示此按钮。
全局组Global Group与所有布局中使用该组的任务小部件共享启动器。
滚动
滚动 高级Scrolling任务超出可用空间时启用滚动。
手动 高级Manual选择“禁用滚动”“仅垂直/水平滚动”或“水平和垂直滚动”。单方向选项取决于停靠栏方向。
自动 高级Automatic开启或关闭自动滚动。
操作
左键单击 高级Left Click左键单击任务时的操作：无、关闭窗口或组、新实例、最小化/还原、切换任务、切换任务分组、展示窗口、预览窗口、高亮窗口，或预览并高亮窗口。
中键单击 高级Middle Click中键单击任务时的操作，选择范围与左键单击相同。
悬停 高级Hover悬停操作：无、预览窗口、高亮窗口，或预览并高亮窗口。任务标题提示由“行为”页控制。
滚轮 高级Wheel滚轮操作：无、切换任务，或切换并最小化任务。
修饰键 + 点击 高级Modifier + click按住 Shift、Ctrl、Alt 或 Meta 再左/中/右键单击，执行额外操作。选择修饰键、鼠标键和动作；它与上面的主要操作分别设置。

Plasma 6 中 KActivities 支持不可靠，因此“仅显示当前活动的任务”过滤器当前被隐藏。

配置 Latte

“布局编辑器”管理布局及其停靠栏；“首选项”控制应用全局行为。“应用”保存当前标签页的待处理修改，“重置”恢复该页的已保存状态，“恢复默认”准备默认值供你确认。“屏幕…”管理已保存的屏幕引用。

窗口中的选项用途与范围

独立副本与克隆

“复制”和“克隆”在屏幕上看起来相似，但行为不同。副本是全新的、独立的停靠栏；克隆是同一个停靠栏在另一块屏幕上的联动视图。是否需要单独配置这个停靠栏，决定你应该选择哪一种。

创建独立副本

请在原始停靠栏上使用以下任一方式，不要在克隆上操作：

  • 右键单击停靠栏，选择复制停靠栏。
  • 打开编辑 Dock，选择添加… → 复制停靠栏。
  • 打开配置 Latte → 布局编辑器 → 停靠栏…，选中停靠栏后选择复制。

副本会获得新的停靠栏和小部件 ID，并一次性复制当前设置。之后可以独立修改它的屏幕、边缘、大小、外观、行为、小部件和启动器。它在布局中是独立条目，可用移除停靠栏删除。

在“停靠栏”对话框中复制克隆，得到的仍然是同一原始停靠栏的克隆，而不是独立副本。若要基于克隆创建独立停靠栏，请先选择编辑原始停靠栏…，再复制原始停靠栏。

如果原始停靠栏使用全局组，副本也会使用该组并共享启动器。若希望副本拥有独立的启动器列表，请在副本上选择唯一组。布局组仅在停靠栏已经使用它时才可用。

创建克隆

克隆由原始停靠栏的屏幕模式创建，而不是通过复制停靠栏：

  • 编辑 Dock → 屏幕 → 所有屏幕：原始停靠栏保留在主屏幕，Latte 会在每个次要屏幕上创建一个克隆。
  • 编辑 Dock → 屏幕 → 所有次要屏幕：原始停靠栏保留在其中一个次要屏幕，Latte 会在其余次要屏幕上创建克隆。

屏幕布局变化时，Latte 会自动创建和移除克隆。要移除克隆，请把原始停靠栏改回在主屏幕，或改为某个具体屏幕。克隆的右键菜单中没有移除停靠栏；请使用其中的编辑原始停靠栏…进行配置。

从克隆打开编辑器时，实际打开的是原始停靠栏的设置，因为克隆共享停靠栏配置。在克隆上修改小部件设置也会更新原始停靠栏。
