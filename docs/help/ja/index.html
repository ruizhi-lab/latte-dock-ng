ドックを編集

変更はすぐに反映されます。「閉じる」はエディターを非表示にしますが、変更を取り消すわけではありません。「ピン留め」はエディターを開いたままにします。「追加… → ドックを複製」は、元のドックの独立したコピーを作成します。「削除」は現在のドックを削除します。タブを切り替えてもウィンドウの位置は変わりません。高度なモードでは、利用可能なスクリーンスペース内で、最も長いページに合わせてウィンドウのサイズが調整されます。長いページはウィンドウ内でスクロールします。ウィンドウのサイズは、どちらの編集モードでも、リサイズコーナーをドラッグして調整できます。

高度なモードでは、より多くのコントロールが表示されます。高度な設定としてマークされたオプションは、基本エディターでは非表示になります。

タスク

アイコンをドロップした後、ランチャーリストを共有する他のドックでタスクランチャーの並び替えが始まります。並び順が確定するまでに少し時間がかかる場合があります。受信側のドックが新しい並び順を保存する際、セパレーターの隙間はそのまま維持されます。すでにピン留めされているアプリをドラッグすると、そのランチャーは既存のまま保持されます。これは、そのランチャーがシステムデフォルトのアプリケーションに従っている場合も同様です。新しいセパレーターは、選択された隙間に配置されるとスペースを占有します。

タスクエリアやシステムトレイの端にあるセパレーターの横にウィジェットを追加またはドラッグすると、ウィジェットはセパレーターの外側に配置されます。セパレーターはタスクエリアやトレイの隣に留まります。

アプリケーションメニューからアプリをピン留めすると、そのアイコンはタスクリストの末尾にあるセパレーターの前に表示されます。右側のセパレーターはピン留めグループに属しているため、ピン留めされていない実行中のアプリはそのセパレーターの向こう側に表示されます。

タスクを並び替えるためにドラッグしている間、タスクリストのスロットはハイライトされたままになり、アイコンは表示され続けます。新しいタスクがスライドインする際、ドックは初期アニメーションサイズからそのスロットの確保を開始します。

バッジ、アニメーション、スクロール、アクション、および一部のインタラクション/フィルターオプションは、アドバンストモードが必要です。ランチャーのみを表示し、すべてのタスクを非表示にすると、ウィンドウ関連のアクションとフィルターが無効になります。

独立したコピーとクローン

重複とクローンは画面上では似ていますが、動作が異なります。重複は新しい独立したドックです。クローンは別の画面に表示される同じドックです。このドックを個別に設定するかどうかに基づいて選択してください。

独立したコピーを作成する

クローンではなく、元のドックでこれらのいずれかの方法を使用します：

  • ドックを右クリックし、ドックを複製を選択します。
  • を開き、ドックを編集を選択し、追加… → ドックを複製を選択します。
  • を開き、Latte を設定 → レイアウトエディタ → ドック…、ドックを選択し、複製を選択します。

コピーは新しいドックIDとウィジェットIDを受け取り、現在の設定を一度だけコピーします。その後、画面、エッジ、サイズ、外観、動作、ウィジェット、ランチャーを独立して変更できます。レイアウト内の別エントリであり、ドックを削除で削除できます。

ドックダイアログからクローンを複製すると、同じ元の別のクローンが作成され、独立したドックにはなりません。クローンから独立したドックを作成するには、まず元のドックを編集…を開き、元を複製します。

元がグローバルグループを使用している場合、コピーもそれを使用し、ランチャーを共有します。別のランチャーリストが必要な場合は、コピーでユニークグループを選択します。レイアウトグループは、ドックがすでにそれを使用している場合にのみ利用可能です。

クローンを作成

クローンは、元のドックの画面モードによって作成され、ドックの複製:

  • ドックの編集 → 画面 → すべての画面: 元のドックはプライマリ画面に留まり、Latteはすべてのセカンダリ画面にクローンを作成します。
  • ドックの編集 → 画面 → すべてのセカンダリ画面: 元のドックは1つのセカンダリ画面に留まり、Latteは残りのセカンダリ画面にクローンを作成します。

Latteは、画面レイアウトが変更されると、クローンを自動的に作成および削除します。クローンを削除するには、元のドックをプライマリ画面または特定の1つの画面に設定し直してください。クローンには、コンテキストメニューにドックの削除という項目はありません。代わりに元のドックを編集…を使用して設定を変更してください。

クローンからエディターを開くと、常に元のドックの設定が開きます。これは、クローンがドックの設定を共有しているためです。クローンで変更されたウィジェットの設定も、元のドックに反映されます。
