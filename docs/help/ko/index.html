독 편집

변경 사항은 즉시 적용됩니다. 닫기는 편집기를 숨기며 변경 사항을 취소하지 않습니다. 고정하기는 편집기를 열린 상태로 유지합니다. 추가… → 독 복제하기는 원본 독의 독립 복사본을 생성합니다. 제거는 현재 독을 제거합니다. 탭을 전환해도 창 위치는 그대로 유지됩니다. 고급 모드는 사용 가능한 화면 공간 내에서 가장 긴 페이지에 맞춰 창 크기를 조정합니다. 더 긴 페이지는 창 내부에서 스크롤됩니다. 창 크기를 조정하려면 두 편집 모드 모두에서 크기 조정 모서리를 드래그하십시오.

macOS 스타일 점 사용외관 설정에서 컴팩트 작업 표시자가 활성화된 경우 Latte 표시자는 기본적으로 macOS 스타일의 점을 사용합니다. 효과를 위해 'macOS 스타일 점 사용'을 끄면 선 또는 점을 수동으로 선택할 수 있습니다.
응용 프로그램 아이콘 색상 사용각 응용 프로그램 아이콘의 주요 색상으로 작업 표시자를 색칠할 수 있으며, 배경 대비에 맞게 조정됩니다. 색상 밑줄을 선택하려면 '선'을 선택하세요. 기본적으로 비활성화되어 있으며, 앱릿은 팔레트 색상을 유지합니다.

작업

아이콘을 놓은 후 런처 목록을 공유하는 다른 독에서 작업 런처의 순서가 재배열되기 시작합니다. 순서가 확정되는 데 시간이 걸릴 수 있습니다. 수신 독이 새 순서를 저장할 때 구분선 간격은 그대로 유지됩니다. 이미 고정된 앱을 드래그하면 기존 런처가 유지되며, 해당 런처가 시스템 기본 애플리케이션을 따르는 경우에도 동일합니다. 새 구분선은 선택된 간격에 도달하면 공간을 차지합니다.

작업 영역 또는 시스템 트레이 가장자리의 구분선 옆에 위젯을 추가하거나 드래그하면, 위젯은 구분선 바깥쪽에 배치됩니다. 구분선은 작업 영역 또는 트레이 옆에 그대로 유지됩니다.

애플리케이션 메뉴에서 앱을 고정하면, 아이콘이 작업 목록 끝의 모든 구분선 앞에 나타납니다. 오른쪽 구분선은 고정된 그룹에 속하므로, 고정되지 않은 실행 중인 앱은 그 뒤에 표시됩니다.

작업을 드래그하여 순서를 재배열하는 동안 작업 슬롯은 강조 표시된 상태로 유지되고 아이콘은 계속 표시됩니다. 새 작업이 슬라이드 인될 때, 독은 초기 애니메이션 크기부터 해당 슬롯을 예약하기 시작합니다.

배지, 애니메이션, 스크롤, 작업 및 일부 상호작용/필터 옵션은 고급 모드가 필요합니다. 런처만 표시하고 모든 작업을 숨기면 창 관련 작업 및 필터가 비활성화됩니다.

화면 목록더 이상 연결되지 않은 화면을 포함하여 Latte에 저장된 화면 참조를 나열합니다.
오래된 화면 선택더 이상 존재하지 않는 화면만 선택합니다. 활성 화면 및 레이아웃에서 사용하는 화면은 제거할 수 없습니다.
모두 선택 해제다른 집합을 선택하기 전에 선택을 지웁니다.

컨텍스트 메뉴 작업

항상 표시할 독 작업을 선택하려면 설정 → 컨텍스트 메뉴 → 작업...을 여십시오.

창 내 옵션제어 대상
항상 접근 가능이 목록의 작업은 독의 컨텍스트 메뉴에 항상 표시됩니다.
편집 모드에서만 접근 가능이 목록의 작업은 독을 편집하는 동안에만 표시됩니다. 목록 간에 작업을 이동하여 이를 변경합니다.
목록 간 이동작업을 선택하고 화살표 버튼을 사용하여 이동합니다. 재설정 및 기본값 복원은 기본 설정 집합을 복원합니다.

독립적인 복사본 및 클론

중복본과 클론은 화면에서 유사해 보이지만 동작 방식이 다릅니다. 중복본은 새로운 독립적인 독입니다. 클론은 다른 화면에 표시되는 동일한 독입니다. 이 독을 별도로 구성할지 여부에 따라 선택하십시오.

독립적인 복사본 생성

클론이 아닌 원본 독에서 다음 방법 중 하나를 사용하십시오:

  • 독을 마우스 오른쪽 버튼으로 클릭하고 독 복제를 선택합니다.
  • 를 열고 독 편집를 선택한 후 추가… → 독 복제를 선택합니다.
  • 를 열고 Latte 구성 → 레이아웃 편집기 → 독들…에서 독을 선택하고 복제를 선택합니다.

복사본은 새로운 독 및 위젯 ID를 받으며 현재 설정을 한 번 복사합니다. 이후에는 화면, 가장자리, 크기, 모양, 동작, 위젯 및 실행기를 독립적으로 변경할 수 있습니다. 이는 레이아웃의 별도 항목이며 독 제거로 제거할 수 있습니다.

독 대화상자에서 클론을 복제하면 독립적인 독이 아니라 동일한 원본의 다른 클론이 생성됩니다. 클론에서 독립적인 독을 만들려면 먼저 원본 독 편집…을 열고 원본을 복제하십시오.

원본이 전역 그룹을 사용하는 경우, 복사본도 이를 사용하며 실행기를 공유합니다. 별도의 실행기 목록을 원한다면 복사본에서 고유 그룹을 선택하십시오. 레이아웃 그룹 은 독이 이미 이를 사용하는 경우에만 사용할 수 있습니다.

클론 생성

클론은 원본 독의 화면 모드에 의해 생성되며, 독 복제:

  • 독 편집 → 화면 → 모든 화면: 원본은 주 화면에 남고, Latte는 모든 보조 화면에 클론을 생성합니다.
  • 독 편집 → 화면 → 모든 보조 화면: 원본은 하나의 보조 화면에 남고, Latte는 나머지 보조 화면에 클론을 생성합니다.

Latte는 화면 레이아웃이 변경될 때 클론을 자동으로 생성 및 제거합니다. 클론을 제거하려면 원본을 주 화면 또는 특정 화면으로 다시 설정하십시오. 클론의 컨텍스트 메뉴에는 독 제거 항목이 없습니다. 대신 원본 독 편집… 를 사용하여 구성하십시오.

클론에서 편집기를 열면 항상 원본 독의 설정이 열립니다. 이는 클론이 독 구성을 공유하기 때문입니다. 클론에서 변경된 위젯 설정도 원본에 업데이트됩니다.
