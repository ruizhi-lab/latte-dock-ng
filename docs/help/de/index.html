Dock bearbeiten

Änderungen werden sofort wirksam. Schließen verbirgt den Editor; es werden keine Änderungen rückgängig gemacht. Anheften hält den Editor offen. Hinzufügen… → Dock duplizieren erstellt eine unabhängige Kopie eines ursprünglichen Docks; Entfernen entfernt das aktuelle Dock. Das Wechseln der Tabs hält das Fenster an Ort und Stelle. Der erweiterte Modus passt die Fenstergröße an die längste Seite an, innerhalb des verfügbaren Bildschirmbereichs. Längere Seiten scrollen innerhalb des Fensters. Ziehen Sie die Ecke zum Ändern der Größe, um die Fenstergröße in beiden Bearbeitungsmodi anzupassen.

Der erweiterte Modus zeigt weitere Steuerelemente an. Optionen, die als Erweitert markiert sind, werden im Basis-Editor ausgeblendet.

Tasks

Task-Launcher beginnen sich auf anderen Docks, die die Launcher-Liste teilen, neu anzuordnen, nachdem Sie das Symbol abgelegt haben. Die Reihenfolge kann einen Moment brauchen, um sich zu stabilisieren. Trennstrich-Abstände bleiben erhalten, wenn das empfangende Dock die neue Reihenfolge speichert. Das Ziehen einer bereits angehefteten App behält ihren bestehenden Launcher bei, auch wenn dieser der Standardanwendung des Systems folgt. Neue Trennstriche nehmen Platz ein, sobald sie die ausgewählte Lücke erreichen.

Wenn Sie ein Widget neben einem Trennstrich am Rand des Aufgabenbereichs oder des System-Trays hinzufügen oder ziehen, wird das Widget außerhalb des Trennstrichs platziert. Der Trennstrich bleibt neben dem Aufgabenbereich oder Tray.

Wenn Sie eine App aus dem Anwendungsmenü anheften, erscheint ihr Symbol vor allen Trennstrichen am Ende der Aufgabenliste. Der rechte Trennstrich gehört zur angehefteten Gruppe, sodass ausgeführte Apps, die nicht angeheftet sind, dahinter erscheinen.

Der Aufgaben-Slot bleibt hervorgehoben und das Symbol bleibt sichtbar, während Sie es ziehen, um die Aufgaben neu anzuordnen. Wenn eine neue Aufgabe einrutscht, beginnt das Dock, ihren Slot ab der anfänglichen Animationsgröße zu reservieren.

Abzeichen, Animationen, Scrollen, Aktionen und einige Interaktions-/Filteroptionen erfordern den Erweiterten Modus. Nur Launcher anzeigen und alle Aufgaben ausblenden deaktiviert fensterbezogene Aktionen und Filter.

Unabhängige Kopien und Klone

Eine Duplizierung und ein Klon sehen auf dem Bildschirm ähnlich aus, verhalten sich jedoch unterschiedlich. Eine Duplizierung ist ein neues, unabhängiges Dock. Ein Klon ist dasselbe Dock, das auf einem anderen Bildschirm angezeigt wird. Wählen Sie basierend darauf, ob Sie dieses Dock separat konfigurieren möchten.

Eine unabhängige Kopie erstellen

Verwenden Sie eine dieser Methoden am ursprünglichen Dock, nicht an einem Klon:

  • Klicken Sie mit der rechten Maustaste auf das Dock und wählen Sie Dock duplizieren.
  • Öffnen Sie Dock bearbeiten und wählen Sie Hinzufügen… → Dock duplizieren.
  • Öffnen Sie Latte konfigurieren → Layout-Editor → Docks…, wählen Sie das Dock aus und wählen Sie Duplizieren.

Die Kopie erhält neue Dock- und Widget-IDs und kopiert die aktuellen Einstellungen einmalig. Danach können Sie Bildschirm, Kante, Größe, Aussehen, Verhalten, Widgets und Launcher unabhängig voneinander ändern. Es ist ein separater Eintrag im Layout und kann mit Dock entfernen entfernt werden.

Das Duplizieren eines Klons im Dialog „Docks“ erstellt einen weiteren Klon desselben Originals, kein unabhängiges Dock. Um ein unabhängiges Dock aus einem Klon zu erstellen, öffnen Sie zuerst Original-Dock bearbeiten… und duplizieren Sie das Original.

Wenn das Original Globale Gruppe verwendet, verwendet die Kopie diese ebenfalls und teilt sich Launcher. Wählen Sie Eindeutige Gruppe an der Kopie, wenn Sie eine separate Launcher-Liste wünschen. Layout-Gruppe ist nur verfügbar, wenn das Dock es bereits verwendet.

Klone erstellen

Klone werden durch den Bildschirmmodus eines Original-Docks erstellt, nicht durch Dock duplizieren:

  • Dock bearbeiten → Bildschirm → Auf allen Bildschirmen: Das Original bleibt auf dem primären Bildschirm, und Latte erstellt einen Klon auf jedem sekundären Bildschirm.
  • Dock bearbeiten → Bildschirm → Auf allen sekundären Bildschirmen: Das Original bleibt auf einem sekundären Bildschirm, und Latte erstellt Klone auf den verbleibenden sekundären Bildschirmen.

Latte erstellt und entfernt Klone automatisch, wenn sich das Bildschirm-Layout ändert. Um Klone zu entfernen, setzen Sie das Original zurück auf Auf primärem Bildschirm oder auf einen bestimmten Bildschirm. Ein Klon hat keinen Dock entfernen-Eintrag in seinem Kontextmenü; verwenden Sie dort Original-Dock bearbeiten…, um es zu konfigurieren.

Das Öffnen des Editors von einem Klon aus öffnet immer die Einstellungen des Original-Docks, da Klone die Dock-Konfiguration teilen. Auf einem Klon geänderte Widget-Einstellungen aktualisieren auch das Original.
