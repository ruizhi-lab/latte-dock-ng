Editar Dock

Le cambios ha effecto immediatemente. Celer celate le editor; illo non disface le cambios. Fixar mantene le editor aperte. Adder… → Duplicar Dock crea un copia independente de un dock original; Remover remove le dock actual. Cambiar de schedas mantene le fenestra in loco. Le modo avantiate dimensiona le fenestra pro su pagina le plus longe, intra le spatio de schermo disponibile. Le paginas plus longe defila intra le fenestra. Trahe le angulo de redimensionamento pro ajustar le dimension del fenestra in ambe modos de editing.

Le modo avantiate revela plus controlos. Optiones marcate Avantiate es celate in le editor basic.

Activitates

Le lancitores de task comencia a reordinar se in altere docks que comparti le lista de lancitores post que tu lassa cader le icone. Le ordine pote require un momento pro stabilisar se. Le spatios de separation resta in loco quando le dock recipient salve le nove ordine. Traxer un app jam fixate conserva su lancitor existente, includente quando ille lancitor seque le application predefinite del systema. Le nove separationes occupa spatio un vice que illos attinge le spatio seligite.

Quando tu adde o traxa un widget al latere de un separation al bordo del area de task o del tray de systema, le widget va al exterior del separation. Le separation resta proxime al area de task o al tray.

Quando tu fixa un app ab le menu de application, su icone appare ante omne separationes al fin del lista de task. Le separation dextre pertine al gruppo fixate, dunque le apps currente que non es fixate appare ultra illo.

Le spacio de task resta highlightate e le icone remane visibile durante que tu lo traxa pro reordinar le tasks. Quando un nove task glissa intra, le dock comencia a reservar su spacio ab le dimension initial del animation.

Insignias, Animationes, Scrolling, Actiones e alcun optiones de Interaction/Filtros require le modo Advance. Monstrar solmente le lancitores e celar omne le tasks disactiva le actiones e filtros relate al fenestras.

Copias Independente e Clones

Un duplicato e un clone appare similar sur le schermo ma se comporta differentemente. Un duplicato es un nove dock independente. Un clone es le mesme dock monstrate sur un altere schermo. Selige basate sur si tu vole configurar iste dock separatamente.

Crear un copia independente

Usa qualcunque de iste methodos sur le dock original, non sur un clone:

  • Clicca con le button dextra sur le dock e selige Duplicar Dock.
  • Aperi Editar Dock e selige Adder… → Duplicar Dock.
  • Aperi Configurar Latte → Editor de Layouts → Docks…, selige le dock, e selige Duplicar.

Le copia recipe nove IDs de dock e de widget e copia le configurationes actual un vice. Post isto, tu pote cambiar su schermo, bordo, dimension, apparentia, comportamento, widgets e launchers independentemente. Es un entry separate in le layout e pote esser removite con Remover Dock.

Duplicar un clone ab le dialogo Docks crea un altere clone del mesme original, non un dock independente. Pro construer un dock independente ab un clone, prime aperi Editar Dock Original… e duplica le original.

Si le original usa Global Group, le copia anque lo usa e comparti launchers. Selige Unique Group sur le copia si tu vole un lista de launcher separate. Layout Group es disponibile solmente quando le dock jam lo usa.

Crear clones

Le clones es create per le modo de schermo de un dock original, non per Duplicar Dock:

  • Editar Dock → Schermo → In Omne Schermos: le original resta in le schermo principal, e Latte crea un clone in cata schermo secundari.
  • Editar Dock → Schermo → In Omne Schermos Secundari: le original resta in un schermo secundari, e Latte crea clones in le restante schermos secundari.

Latte crea e remove clones automaticamente quando le disposition del schermo cambia. Pro remover clones, fixa le original de novo a In Schermo Principal o a un schermo specific. Un clone non ha un entry Remover Dock in su menu de contexto; usa Editar Dock Original… ibi pro configurar lo.

Aperir le editor ab un clone sempre aperi le parametros del dock original, proque le clones comparti le configuration del dock. Le parametros del widget cambiate in un clone actualisa anque le original.
