Guia do Usuário do Latte Dock NG

Estas instruções descrevem as opções atuais. O modo avançado, o estilo da dock e os plugins instalados podem alterar quais controles são visíveis. As opções marcadas como Avançado ficam ocultas no editor básico.

Editar Dock

As alterações entram em vigor imediatamente. Fechar oculta o editor; não desfaz as alterações. Fixar mantém o editor aberto. Adicionar… → Duplicar Dock cria uma cópia independente de uma dock original; Remover remove a dock atual. Alternar entre as abas mantém a janela no lugar. O modo avançado dimensiona a janela para sua página mais longa, dentro do espaço de tela disponível. Páginas mais longas rolam dentro da janela. Arraste o canto de redimensionamento para ajustar o tamanho da janela em qualquer modo de edição.

O modo avançado revela mais controles. As opções marcadas como Avançado ficam ocultas no editor básico.

Tarefas

Os lançadores de tarefas começam a ser reordenados em outras docks que compartilham a lista de lançadores após você soltar o ícone. A ordem pode levar um momento para se estabilizar. Os espaços dos separadores permanecem no lugar quando a dock receptora salva a nova ordem. Arrastar um aplicativo já fixado mantém seu lançador existente, inclusive quando esse lançador segue o aplicativo padrão do sistema. Novos separadores ocupam espaço assim que atingem o intervalo selecionado.

Ao adicionar ou arrastar um widget ao lado de um separador na borda da área de tarefas ou da bandeja do sistema, o widget é colocado do lado de fora do separador. O separador permanece ao lado da área de tarefas ou da bandeja.

Ao fixar um aplicativo pelo menu de aplicativos, seu ícone aparece antes de quaisquer separadores no final da lista de tarefas. O separador à direita pertence ao grupo fixado, portanto, aplicativos em execução que não estão fixados aparecem além dele.

O espaço da tarefa permanece destacado e o ícone continua visível enquanto você o arrasta para reordenar as tarefas. Quando uma nova tarefa desliza para dentro, a dock começa a reservar seu espaço a partir do tamanho inicial da animação.

Selos, Animações, Rolagem, Ações e algumas opções de Interação/Filtros exigem o modo Avançado. Mostrar apenas lançadores e ocultar todas as tarefas desativa ações e filtros relacionados a janelas.

Áudio tocando de tarefas AvançadoMostrar um selo de áudio para aplicativos que estão reproduzindo som. A correspondência prefere identificadores explícitos de desktop/aplicativo. Informações genéricas do processo do navegador não são suficientes para identificar um PWA específico; fluxos ambíguos são deixados sem atribuição em vez de fornecer controles de áudio a aplicativos não relacionados. Aplicativos Electron independentes ainda podem corresponder ao seu próprio processo de áudio. O status de reprodução e a atividade de saída ocultam fluxos pausados, mesmo quando o aplicativo mantém sua conexão de áudio aberta. Sem o status do player, um breve silêncio é tolerado por cerca de um segundo.

Configurar Latte

O Editor de Layouts gerencia layouts e seus docks. As Preferências controlam o comportamento do aplicativo como um todo. Aplicar salva as alterações pendentes na aba atual; Restaurar recupera o estado salvo dessa aba; Restaurar Padrões prepara os padrões para revisão. Telas... gerencia referências de telas armazenadas.

Cópias Independentes e Clones

Uma duplicata e um clone parecem semelhantes na tela, mas se comportam de maneira diferente. Uma duplicata é uma nova dock independente. Um clone é a mesma dock exibida em outra tela. Escolha com base em se deseja configurar esta dock separadamente.

Criar uma cópia independente

Use qualquer um destes métodos na dock original, não em um clone:

  • Clique com o botão direito na dock e escolha Duplicar Dock.
  • Abra Editar Dock e escolha Adicionar… → Duplicar Dock.
  • Abra Configurar Latte → Editor de Layouts → Docks…, selecione a dock e escolha Duplicar.

A cópia recebe novos IDs de dock e widget e copia as configurações atuais uma vez. Depois disso, você pode alterar sua tela, borda, tamanho, aparência, comportamento, widgets e lançadores independentemente. É uma entrada separada no layout e pode ser removida com Remover Dock.

Duplicar um clone a partir do diálogo Docks cria outro clone do mesmo original, não uma dock independente. Para criar uma dock independente a partir de um clone, primeiro abra Editar Dock Original… e duplique o original.

Se o original usa Grupo Global, a cópia também o usa e compartilha lançadores. Escolha Grupo Único na cópia se você quiser uma lista de lançadores separada. Grupo de Layout está disponível apenas quando o dock já o utiliza.

Criar clones

Os clones são criados pelo modo de tela de um dock original, não por Duplicar Dock:

  • Editar Dock → Tela → Em Todas as Telas: o original permanece na tela principal, e o Latte cria um clone em cada tela secundária.
  • Editar Dock → Tela → Em Todas as Telas Secundárias: o original permanece em uma tela secundária, e o Latte cria clones nas telas secundárias restantes.

O Latte cria e remove clones automaticamente quando o layout da tela muda. Para remover clones, defina o original de volta para Na Tela Principal ou para uma tela específica. Um clone não possui a entrada Remover Dock em seu menu de contexto; use Editar Dock Original… lá para configurá-lo.

Abrir o editor a partir de um clone sempre abre as configurações do dock original, porque os clones compartilham a configuração do dock. As configurações de widgets alteradas em um clone também atualizam o original.
