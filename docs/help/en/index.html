Edit Dock

Changes take effect immediately. Close hides the editor; it does not undo changes. Pin keeps the editor open. Add… → Duplicate Dock creates an independent copy of an original dock; Remove removes the current dock.

Advanced mode reveals more controls. Options marked Advanced are hidden in the basic editor.

Independent Copies and Clones

A duplicate and a clone look similar on screen but behave differently. A duplicate is a new, independent dock. A clone is the same dock shown on another screen. Choose based on whether you want to configure this dock separately.

Create an independent copy

Use any of these methods on the original dock, not on a clone:

  • Right-click the dock and choose Duplicate Dock.
  • Open Edit Dock and choose Add… → Duplicate Dock.
  • Open Configure Latte → Layouts Editor → Docks…, select the dock, and choose Duplicate.

The copy receives new dock and widget IDs and copies the current settings once. After that, you can change its screen, edge, size, appearance, behavior, widgets and launchers independently. It is a separate entry in the layout and can be removed with Remove Dock.

Duplicating a clone from the Docks dialog creates another clone of the same original, not an independent dock. To build an independent dock from a clone, first open Edit Original Dock… and duplicate the original.

If the original uses Global Group, the copy also uses it and shares launchers. Choose Unique Group on the copy if you want a separate launcher list. Layout Group is only available when the dock already uses it.

Create clones

Clones are created by the screen mode of an original dock, not by Duplicate Dock:

  • Edit Dock → Screen → On All Screens: the original stays on the primary screen, and Latte creates a clone on every secondary screen.
  • Edit Dock → Screen → On All Secondary Screens: the original stays on one secondary screen, and Latte creates clones on the remaining secondary screens.

Latte creates and removes clones automatically when the screen layout changes. To remove clones, set the original back to On Primary Screen or to one specific screen. A clone has no Remove Dock entry in its context menu; use Edit Original Dock… there to configure it.

Opening the editor from a clone always opens the original dock’s settings, because clones share the dock configuration. Widget settings changed on a clone also update the original.
