# Mageia Cauldron CI dependency failure

[Build run 43577686480](https://github.com/ruizhi-lab/latte-dock-ng/actions/runs/43577686480)
on `838b32b39` completed with 21 successful jobs and two Mageia failures.
Retrying the failed jobs produced the same two failures. Both failed while
installing dependencies for `docker/Dockerfile.mageia`, before the project was
built: the Cauldron `autoconf-archive-2026.11.11-1.mga11.noarch` package
required the literal capability `typelib($1)`, for which DNF found no provider.
The dependency chain included Plasma workspace development packages, Flatpak,
malcontent, Vala and `gnome-common`.

The CI mirror's partially retrieved repository metadata also contained that
package and literal requirement. The metadata download did not complete, so it
does not establish whether the same repository snapshot offered an older
version. Other public mirror directory listings showed an older RPM, but a
directory listing alone does not prove it is in the CI mirror's active solver
metadata. No package exclusion, `--skip-broken` or dependency removal was
introduced; the Mageia validation remains failed pending an upstream fix or a
separately verified solution that preserves the required dependencies.
