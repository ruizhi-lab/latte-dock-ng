## Inventory and decision

| Property | Source and lifetime | Type decision |
| --- | --- | --- |
| `theme` | `Kirigami.Theme` attached object owned by the host; read by palette bindings. | Keep `var`. A local fixed type would depend on the host's attached-type implementation and could affect dynamic palette updates. |
| `units` | `Kirigami.Units` singleton supplied by Kirigami; read by size and spacing bindings. | Keep `var`; this review establishes no benefit from imposing a different local type. |

The only other `property var` in this component is inside a disabled
`MobileCursor` comment block, so it has no runtime value or creation path.
`ScrollArea.qml` has no `property var`. Neither active candidate is a stable
project-owned input; S5b therefore has no justified type conversion. A concise
ownership and update rationale now sits beside the two properties.
