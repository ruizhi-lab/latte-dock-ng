# P4 Fedora observer data

This directory holds the planned synthetic
[`two-trash.layout.latte`](two-trash.layout.latte) fixture and reserves space
for Fedora continuation evidence. The fixture adds two Trash applets to the
built-in default layout. Four bounded private-session attempts and their
launcher/log evidence are retained in [`attempts`](attempts/README.md); the
diagnostic instrumentation failed before establishing the two internal
trackers. Raw samples require all preconditions and a valid live observer
sequence, and each file will include frozen source/build identity and the
private-session environment. The observer
implementation is shared from
[`P4-arch-preflight-data/tools`](../P4-arch-preflight-data/tools/README.md);
no Fedora-specific copy is maintained here.

No valid live sequence or performance data has been collected.
