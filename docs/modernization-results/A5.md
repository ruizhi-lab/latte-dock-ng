## Candidate evidence

- The largest files are large, but size alone does not identify a safe owner or
  stable input/output contract.
- `dockStyleIsModernFromVariant()` is already a small file-local policy helper
  in `containment/plugin/layoutmanager.cpp`.

  production helpers from both positioning and effects code.

  into tested production logic and removed copied test logic. Repeating it is
  unnecessary.
- `View` and `ContainmentInterface` coordinate QObject/QML/plugin state; moving
  responsibilities without a demonstrated ownership defect could introduce a
  second authority or alter lifecycle behavior.

## Decision

Defer another policy extraction. No concrete duplicate implementation, failing
boundary or measured build/maintenance cost was found in this follow-up review.
The existing architecture charter already describes the ownership direction;
creating a target/helper only to reduce line count would add indirection and
regression risk without a supported benefit.

No source behavior changed. No tests or build were run.

## Exact reopen condition

Reopen A5 only when a code review identifies a specific duplicated decision,
ownership/lifetime bug, or measured incremental-build/maintenance cost. Define
its authoritative state, caller boundary and fallback before extraction; keep
the implementation unmodified if a behavior-equivalent test cannot be written.
