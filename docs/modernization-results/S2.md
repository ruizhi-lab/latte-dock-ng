# S2: Explicit QML Wheel Parameters

Status: Complete. Date: 2026-10-01. Branch: `codex/architecture-followup`.
Start HEAD: `76398ef04`.

## Change

`ScrollArea.qml` and both `ComboBox.qml` wheel handlers now declare
`function(wheel)`. The handler bodies, event acceptance, thresholds, throttling,
selection and activation logic are unchanged. Two QML tests exercise the real
components in `autotests/qml/`.
