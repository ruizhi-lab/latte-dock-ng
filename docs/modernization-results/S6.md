## External issue: Fedora Kickoff add-to-Dock action

Disposition: Recorded only; the user requested no external Plasma repair.

In Fedora 44 (Qt 6.11.2, Plasma 6.7.5), choosing Add to Latte Dock for KWrite
from the top Plasma panel's Kickoff menu did nothing. The session journal
recorded `ActionMenu.qml:80: TypeError: Cannot read property 'view' of null`.
The inspected KDE handler accesses `menu.visualParent.view.model` before
dispatching the action. No corresponding Dock add request was observed.

Direct invocation of the installed Latte launcher helper with
`/usr/share/applications/org.kde.kwrite.desktop` exited zero; the Dock's
`hasLauncher` D-Bus method confirmed the addition. The temporary KWrite and
Kate launchers used during investigation were removed afterwards. The user
reports that the same menu integration works on their Gentoo host.

These observations point to the Fedora Plasma/Kickoff action path rather
than a failure of Latte's add-launcher API. The exact Qt, Plasma, packaging or
session-state cause was not established, and Gentoo's corresponding versions
were not compared. No Plasma patch was deployed, and no Latte runtime change
was made for this report.
