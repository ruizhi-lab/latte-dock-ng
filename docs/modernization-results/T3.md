## Wake-up fixture refinement

Initial probes using a bare wait call, an unbraced conditional, and POSIX
`pthread_cond_wait` did not trigger this C++ check. A separate real-header probe
found that a braced `if (ready) { condition.wait(lock); }` is diagnosed under
the production flags on both tool versions. The accepted fixture uses that API
shape and preserves the invalid non-loop wait so the check's intended finding
is the one that fails the fixture.

## Fixture proof

The production Clang Debug compile command for `app/lattecorona.cpp` supplied
the flags for all fixtures. The runner's `prove_fixtures()` retargeted that
command to temporary copies. Each invocation used four jobs and proved all 46
fixtures under `WarningsAsErrors: '*'` with zero fixture translation-unit
problems:

```sh
for TIDY_PATH in /usr/lib/llvm/22/bin /tmp/latte-llvm18/bin; do
  PATH="$TIDY_PATH:$PATH" python3 - <<'PYPROOF'
import importlib.util, json, shutil, sys
from pathlib import Path
root = Path.cwd()
spec = importlib.util.spec_from_file_location("tidy_gate", root / "scripts/test-clang-tidy.py")
mod = importlib.util.module_from_spec(spec)
sys.modules[spec.name] = mod
spec.loader.exec_module(mod)
build = root / "build/modernization/clang-debug"
entries = json.loads((build / "compile_commands.json").read_text())
selected, _ = mod.CLAZY_GATE.select_translation_units(entries, build.resolve())
flags = next(e for e in selected if mod.CLAZY_GATE.unit_path(e) == mod.FIXTURE_FLAGS_SOURCE)
mod.prove_fixtures(shutil.which("clang-tidy"), flags, 4)
PYPROOF
done
```

Both printed `46 negative fixtures: each is rejected as an error by its own
gated check` (host elapsed 0.965 s; LLVM 18 wrapper elapsed 1.145 s after
formatting). Logs: [clang-tidy 22 fixture proof](T3-data/fixtures22.txt) and
[clang-tidy 18 fixture proof](T3-data/fixtures18.txt). The proof selected the
`app/lattecorona.cpp` entry from `build/modernization/clang-debug/compile_commands.json`
and called `prove_fixtures(clang_tidy, flags, 4)` from
`scripts/test-clang-tidy.py`.

The LLVM 18 wrapper is an isolated clang-tidy 18.1.3 tool run using the
existing compile database and GCC 13 C++ headers; it is tool-version coverage,
not CI parity. See the [environment recipe](T1-data/README.md).
