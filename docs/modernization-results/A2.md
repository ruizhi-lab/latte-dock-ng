## Evidence

`app/main.cpp::filterDebugMessageOutput` is installed as the process-wide Qt
message handler. It suppresses exact deprecated-binding messages, but also
contains substring filters for package/toolbox warnings, generated Plasma QML
resources, warning text from Qt/Kirigami types, clipboard load errors and
digital-clock internals. The handler affects what reaches the debug log, so
removing or narrowing a match without confirming its actual emitter can hide
an existing dependency failure or change log volume in either direction.

No readable `/tmp/latte-ng.log` was present during this review. Source text
alone cannot establish which filters match on this supported runtime or
whether any observed line is emitted by a project component.

launch, retest and log review procedure in AGENTS.md is required to collect
representative evidence; the log must be associated with its Plasma/Qt version
and relevant interaction. A future A2 pass should change one message family
