## Excluded candidate

`bugprone-string-constructor` is not promoted in this slice. I tested the
documented oversized literal length (`std::string("test", 200)`) and reversed
fill constructor (`std::string('x', 50)`) patterns using the production compile
flags. Neither emitted a finding with host clang-tidy 22.1.8 against the host
GCC 16 C++ headers. The same isolated trigger probes have not yet been repeated
with clang-tidy 18; the promotion decision remains pending further fixture
investigation rather than treating this check as unsupported.

`bugprone-throw-keyword-missing` does not require an exception expression in
its fixture: constructing `std::runtime_error` without `throw` exercises the
check and compiles under the production `-fno-exceptions` flags. The fixture
proof confirms this without changing runner behavior.
