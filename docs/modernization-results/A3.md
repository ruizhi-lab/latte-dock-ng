# A3: Legacy Justify Splitter Branch Review

Status: Deferred; production code unchanged to protect layout behavior.
Date: 2026-10-01. Branch: `codex/architecture-followup`.
Start HEAD: `81e7d061e`.

## Source review

`LayoutManager::usesLegacyJustifySplitters()` currently always returns false
because panel mode was removed and the supported dock flow uses one applet
sequence. CodeGraph found 11 in-class callers and no covering tests for the
method. The branches are not one interchangeable deletion:

- Some `useJustifySplitters` branches guard loading, ordering or persisting
  splitter positions from configuration.
- `addJustifySplittersInMainLayout()` joins the start/main/end layouts and
  returns when the predicate is false; that join is active behavior and must
  remain.
- `moveAppletsBasedOnJustifyAlignment()` also joins layouts on the false path.
- Other methods return early for the false predicate, making splitter-only
  work unreachable today.
- QML still has a `createJustifySplitter()` entry point and Justify alignment
  behavior, so removing names/config handling requires tracing migration and
  saved layouts, not just trusting the constant return value.

## Decision

Do not remove branches in this slice. The available evidence supports dead
splitter-specific work in some paths, but no production tests or runtime
coverage currently prove the resulting layout, drag order, separator/spacer
placement and persisted-config behavior remain identical. Removing the
predicate wholesale risks deleting the active join-layout path along with dead
code.

No build, tests or desktop checks were run. This is a conservative source review,
not a claim that the branches are proven dead in every restored user layout.

## Reopen criteria and exact next action

Add or identify production-path fixture coverage for old saved Justify
configuration and the start/main/end join behavior, then perform a real desktop
retest covering Justify alignment, separator/spacer arrangement and dragging.
Until both are available, leave the source unchanged and continue A4 analysis.
